# 要件仕様

## 目的
Pokémon TCG Live（PTCGL）は英語版しか提供されていない。対戦中・デッキ構築中に表示される
英語カードを自動で認識し、同じカードの日本語版画像を別ウィンドウに表示することで、
日本語ユーザーがカードの効果を素早く確認できるようにする。

## 対象環境
- Windows 10/11、PTCGL デスクトップ版（ウィンドウ表示・フルスクリーンどちらも対象）
- マルチモニタ環境を想定する（PTCGL と本アプリを別モニタに置く使い方）

## 機能要件

### MUST（v0.1）
1. **画面キャプチャ**: PTCGL のウィンドウを一定間隔（既定 1 秒）でキャプチャする
2. **カード認識**: キャプチャ画像から「現在注目されているカード」を特定する
   - 第一段階は OCR によるカード名＋セット番号（例 `SVI 123/198`）の読み取り
   - 将来的に画像ハッシュ／特徴点マッチングで補強する
3. **日本語カード検索**: 認識した英語カードに対応する日本語カードを特定する
4. **画像表示**: 日本語版カード画像を常時最前面ウィンドウに表示する
5. **キャッシュ**: 取得したカードデータ・画像はローカルに保存し、2 回目以降はオフラインで動作する

### SHOULD
- 認識対象の領域（拡大表示されたカード／手札）を設定で切り替えられる
- 認識履歴（直近 N 枚）を一覧表示し、クリックで再表示できる
- 認識に失敗したカードを手動検索できる
- 対応する日本語版が存在しないカード（英語限定プロモ等）はその旨を表示する

### COULD
- システムトレイ常駐、ホットキーで表示／非表示
- 認識結果のテキスト（日本語カード名・効果）を表示

## 非機能要件
- 認識から表示までの遅延: 2 秒以内を目標
- CPU 負荷: アイドル時 5% 以下（差分がなければ OCR をスキップする）
- 外部 API へのアクセスはキャッシュ優先で最小化する

## データソース（候補）
| 用途 | ソース | 備考 |
| --- | --- | --- |
| 英語カードDB | [Pokémon TCG API](https://pokemontcg.io/) | 名前・セット・番号・画像 |
| 多言語カードDB | [TCGdex API](https://tcgdex.dev/) | 日本語を含む多言語対応。画像 URL あり |
| 日本語公式 | [ポケモンカード公式 カード検索](https://www.pokemon-card.com/card-search/) | 公式画像。スクレイピングは利用規約を要確認 |

**英→日の対応付けは未確定の設計課題。** 英語版と日本語版はセット構成・番号が異なるため、
カード名（英語→日本語の名称テーブル）＋ワザ名／HP などの属性で照合する方式を第一候補とする。
決定事項は [architecture.md](architecture.md) に記録する。

## 対象外
- PTCGL の自動操作・チート行為に当たる機能
- カード画像の再配布
